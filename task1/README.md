# Customer Support MCP Server

This is a stdio MCP server written with the official Python SDK and Pydantic. It has two tools: `get_customer_record`, which takes a `customer_id` like `CUST-12345`, and `trigger_refund`, which takes a `customer_id`, a positive `amount`, and a `reason` of at least 10 characters. To keep stdout clean, the server moves the real stdout to a private file descriptor before anything else is imported and points everything else at stderr, so logs, stray prints, and child process output never reach the client. Bad input comes back as a JSON-RPC `-32602` error listing every field that failed. Malformed messages get `-32700` or `-32600`, unknown methods get `-32601`, and unexpected crashes get `-32603`. Valid requests that can't be completed, like an unknown customer or a refund larger than the balance, return a normal result with `isError: true`. Validation is strict: the ID has to be exactly `CUST-` plus five ASCII digits, amounts must be finite, above 0, at most 10,000, and have no more than two decimal places, and the reason can't just be padded out with spaces. One caveat is that recent MCP spec versions suggest returning validation failures as `isError` results instead, but this task asks for JSON-RPC error codes, so that's what it does. To run it, install the requirements with `pip install -r requirements.txt` from this folder (Python 3.10 or newer), start the server with `python server.py`, and run the tests with `python -m pytest -v`. The tests also run on Windows, macOS, and Linux through GitHub Actions.
